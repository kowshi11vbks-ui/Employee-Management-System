# Employee Management System

## Project Description
Employee Management System is a Java application used to manage employee details. It allows users to add and view employee information.

## Features
- Add Employee
- View Employee Details
- Search Employee
- Update Employee Details
- Delete Employee Details

## Technology Used
- Java

## Files
- Main.java
- README.md

## How to Run
1. Open the project in VS Code or Eclipse.
2. Compile the program:
   javac Main.java
3. Run the program:
   java Main
